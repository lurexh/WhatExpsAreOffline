Public API

Free, auto-updating JSON API for Roblox executor status. No key required, no auth, CORS-enabled. Updated every 6 hours by a GitHub Action.

Base URL https://weaoffline.vercel.app/api
Format JSON · UTF-8
Update cadence Every 6 hours · check meta.json for updatedAt

Quick start

curl https://weaoffline.vercel.app/api/executors.json
const res = await fetch('https://weaoffline.vercel.app/api/executors.json');
const data = await res.json();
console.log(data.count, 'executors tracked');
for (const ex of data.executors) {
  if (ex.banwaveRisk) console.log('⚠', ex.title);
}

Endpoints

GET/api/executors.json
Every executor, in one bundle. This is what the site itself uses.
{
  "updatedAt": "2026-09-26T18:00:00.000Z",
  "version": 1,
  "sources": ["weao.gg", "scriptblox.com"],
  "count": 32,
  "executors": [ /* see Executor schema below */ ]
}
GET/api/executors/{slug}.json
Single executor by slug. Cheap — use this if you only need one.
curl https://weaoffline.vercel.app/api/executors/potassium.json
{
  "slug": "potassium",
  "title": "Potassium",
  "version": "2.5.0",
  "status": "online",
  "sunc": 100,
  "unc": 99,
  "pricing": { "free": false, "cost": "$22.99 Lifetime" }
  /* ...full Executor schema... */
}
GET/api/meta.json
Timestamps and counts. Cheap poll target if you just want to know if data changed.
{
  "updatedAt": "2026-09-26T18:00:00.000Z",
  "count": 32,
  "version": 1
}
GET/api/status.json
Summary counts. Fast to parse, good for status badges.
{
  "updatedAt": "2026-09-26T18:00:00.000Z",
  "banwaveActive": false,
  "banwaveRiskCount": 0,
  "onlineCount": 24,
  "offlineCount": 8,
  "totalCount": 32
}
GET/api/banwaves.json
Historical banwave sessions, newest first. 30 days retention.
{
  "updatedAt": "2026-09-26T18:00:00.000Z",
  "count": 4,
  "sessions": [
    {
      "startedAt": "2026-08-12T10:00:00.000Z",
      "endedAt": "2026-08-13T22:00:00.000Z",
      "peakFlagged": 6,
      "flagged": ["Potassium", "Wave", "..."],
      "durationMs": 129600000
    }
  ]
}

Executor schema

Every entry in executors[] and every /api/executors/{slug}.json response has this shape:

FieldTypeNotes
slugstringURL-safe id, e.g. potassium
titlestringDisplay name
versionstringLatest known version
updatedDatestring | nullHuman-readable last update
platformstring | nullWindows, Mac, Android, iOS
typestringexecutor · external · mac · android
statusstringonline · offline · banwave-risk
banwaveRiskboolTrue if flagged
detectedboolEver seen in a past banwave
detectionReasonstring | nullHuman-readable reason
suncnumber | null0–100
uncnumber | null0–100
pricing.freebool—
pricing.coststring | nulle.g. "$22.99 Lifetime"
creatorstring | null—
descriptionstring | nullPlain text, may contain markdown links
featuresstring[]See feature enum below
links.*string | nullwebsite, discord, purchase, store, showcase
logostring | nullImage URL
viewsnumber | nullScriptBlox view count
sourcesstring[]weao, scriptblox
overridesboolTrue if manually corrected

Rate limits & caching

Please cache. Responses are cached at the CDN for 5–10 minutes. Don't poll more than once every 5 minutes. Use /api/meta.json to check whether data changed before refetching the full bundle.

No authentication, no per-IP rate limit right now. If abuse becomes a problem, one will be added — you'll see it here first.

CORS

Every /api/* response includes:

Access-Control-Allow-Origin: *
Access-Control-Allow-Methods: GET, OPTIONS

Fetch directly from any browser context. No proxy needed.

Versioning

The current API is v1. Every response includes a version field. If a breaking change ever lands, it goes to /api/v2/ and v1 keeps working for at least 90 days. Field additions are not breaking.

Attribution

Data is aggregated from weao.gg and scriptblox.com. If you build something public on top, a link back is appreciated but not required.
